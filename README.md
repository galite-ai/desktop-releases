# Galite for Mac — Alpha

Public installers and release notes for Galite's early Mac alpha. The application source is maintained separately in a private repository.

Check [Releases](https://github.com/galite-ai/desktop-releases/releases) for available signed and notarized alpha installers. If no versioned installer is listed, the public alpha is not available yet. Published installers can be downloaded without a GitHub account.

The planned installer supports Apple Silicon and Intel Macs running macOS 12 or later. Expect bugs, incomplete features, and changes. Supported local-session formats are limited; syncing sends selected material to Galite's hosted service for AI processing.
