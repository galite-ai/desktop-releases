# Galite for Mac — Alpha

Public installers and release notes for Galite’s early Mac alpha. Application source is maintained separately in a private repository.

[Download the Mac alpha](https://galite.ai) · [Release notes](https://github.com/galite-ai/desktop-releases/releases)

The universal installer supports Apple Silicon and Intel Macs running macOS 12 or later. Downloads do not require a GitHub account. Expect bugs, incomplete features, and changes.

## First launch

The first alpha is **ad-hoc signed, not Apple-notarized**. Open the DMG and drag Galite to Applications. Try opening Galite; if macOS blocks it, use **System Settings → Privacy & Security → Open Anyway**, then confirm. Only do this for an installer from this official repository. Do not disable Gatekeeper globally.

Release assets include SHA-256 checksums and a signed updater archive. Updater signing is separate from Apple notarization. Physical Intel installation and a version-to-version update installation have not yet been verified.

Supported local-session formats are limited; syncing sends selected material to Galite’s hosted service for AI processing. See each version’s release notes for limitations.
